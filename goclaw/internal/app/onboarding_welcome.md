# __H1__

## Before you start

**Models can be wrong.** Read replies carefully before you run shell commands or accept edits.

**Untrusted code or pasted text** can try to steer the agent (prompt injection). Use goclaw only on **codebases and inputs you trust**.

`docs/goclaw/security.md` is a path in the source tree — in the terminal it is **not** a link you can click. The same text is bundled in the binary; **Press S** to read it here (scrollable).

Press **Enter** or **Esc** to continue

Press **Ctrl+C** to exit
